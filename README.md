# Robótica educativa — preparación ACECode STA

Proyecto preparado sin modificar el robot. Abrir [QD001_V2_STA_Completo.sb3](acecode/QD001_V2_STA_Completo.sb3) en ACECode y consultar [las instrucciones](acecode/README.md).

La variante conserva los bloques funcionales del programa completo QD001 V2 del fabricante y cambia la preparación de red a STA. Incluye marcadores para completar SSID y clave en una copia local excluida de Git.

El firmware estable sigue sin cambios. La variante no fue compilada, instalada ni probada físicamente. MicroPython continúa como desarrollo futuro separado.

Documentación del proyecto en la rama [documentacion](https://github.com/gonzaloogv/robotica-educativa/tree/documentacion).
